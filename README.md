# まったりアクアリウム 🐠

ブラウザで遊べる、のんびり系の放置育成ゲームです。生き物を育てて水槽を賑やかにしながら、パールを貯めていきます。

## 遊び方

`index.html` を開くだけで遊べます。ビルドもインストールも不要、単一ファイルで完結しています。

- 水槽をタップしてパールを獲得
- パールで生き物を購入（放置していても自動でパールを稼いでくれます）
- パールが貯まると新しいステージ（湖・海・珊瑚礁・深海）が解放されます
- 図鑑・実績・ショップなど、遊んでいるうちにどんどん機能が増えていきます

進行状況はブラウザの `localStorage` に自動保存されます。

## 特徴

- 単一HTMLファイル・外部依存なし・オフラインで動作
- 全36種の生き物、6つのステージ
- 環境改善・進化システム
- 実績・レアな来訪者・ログインボーナスなどのやり込み要素
- オリジナル部屋のカスタマイズ（背景・装飾ショップ）
